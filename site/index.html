nexchat

HexChat, continued.

nexchat is a free, open source IRC client for Linux, BSD, Windows and macOS. It is a continuation of HexChat, whose repository was archived in 2024.

The same HexChat you know: the same layout, menus, dialogs and keybindings, moved onto a current toolkit (GTK4) and kept working. Nothing is redesigned for its own sake.

Source code · Issues · Roadmap

Coming from HexChat

  • On first start, nexchat copies ~/.config/hexchat (or %APPDATA%\HexChat) to its own folder. Your HexChat folder is left as it is.
  • Plugins keep working. The C API is unchanged (hexchat-plugin.h, or the new nexchat-plugin.h).
  • Scripts keep working. Python can use import hexchat or import nexchat, Lua has both names, and Perl has HexChat:: and Nexchat::.
  • Themes (.hct) and colors.conf work the same.
  • The HexChat documentation still applies.

What's different

  • GTK4 on every platform, so HiDPI and Wayland work properly.
  • Colours follow the system's light or dark mode. Colours you set yourself stay as they are.
  • On macOS: the system menu bar, ⌘ shortcuts, a menu bar icon, and a self-contained nexchat.app.
  • The tray icon is native everywhere: StatusNotifierItem on Linux and BSD, the notification area on Windows, a menu bar item on macOS.

Install

Download the latest release from GitHub Releases:

  • Windows: the setup.exe installer, or the portable.zip to run from any folder (settings stay beside it).
  • macOS (Apple Silicon): the .dmg; drag nexchat to Applications. The first time, right-click it and choose Open.
  • Linux: the .flatpak, installed with flatpak install --user nexchat-*.flatpak.

Or build from source with meson; it needs GTK 4.14 or newer, GLib 2.76, OpenSSL and meson 0.59.

Linux and BSD:

git clone https://github.com/1ay1/nexchat
cd nexchat
meson setup build
ninja -C build
./build/src/fe-gtk/nexchat

macOS, with Homebrew:

brew install meson gtk4 openssl@3
git clone https://github.com/1ay1/nexchat
cd nexchat
meson setup build -Ddbus=disabled
ninja -C build app
open build/nexchat.app

Windows, in an MSYS2 UCRT64 shell:

pacman -S mingw-w64-ucrt-x86_64-{gcc,pkg-config,meson,gtk4,gettext,openssl}
git clone https://github.com/1ay1/nexchat
cd nexchat
meson setup build -Ddbus=disabled -Dwith-perl=false
ninja -C build

Questions

Is HexChat discontinued?
Yes. HexChat's repository was archived in 2024, and it never left GTK2. nexchat continues it on GTK4, keeping the layout, menus and keybindings.
Can I keep my HexChat settings, plugins and scripts?
Yes. On first start nexchat copies your HexChat configuration folder and leaves the original alone. C plugins build against the unchanged plugin API, and Python, Perl and Lua scripts keep working under their HexChat names.
Which platforms does nexchat run on?
Linux, the BSDs, Windows and macOS.
Is nexchat free?
Yes. It is free and open source software under the GPL v2, like HexChat and X-Chat before it.
