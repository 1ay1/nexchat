HexChat was archived in 2024. nexchat carries on.

The IRC client you know. Built for today.

nexchat is the HexChat layout, menus, dialogs and keybindings, moved onto GTK4. It runs on Linux, BSD, Windows and macOS, and your config, plugins and scripts come with you.

features

Everything HexChat did. On a toolkit that's still maintained.

Nothing was redesigned for the sake of it. Every window and menu is checked against screenshots of HexChat; what changed is underneath.

layout

Tree or tabs, as you had it

Channel tree, topic bar, user list with mode icons and counts, nick button, input box. Same places, same shortcuts.

gtk4

One modern frontend

GTK4 on every platform, with no deprecated calls. Sharp on HiDPI, at home on Wayland.

appearance

Light and dark, live

The palette follows your system as it switches. Colours you chose yourself stay yours.

macos

A real Mac app

The system menu bar, ⌘ shortcuts, a menu bar icon, a Dock bounce for highlights, and a self-contained nexchat.app.

tray

Native notifications area

StatusNotifierItem on Linux and BSD, the Windows notification area, a macOS menu bar item.

power

Nothing taken away

Python, Perl and Lua scripting, FiSH encryption, DCC, logging, the URL grabber, user commands and popups.

migration

Coming from HexChat? Just open it.

There's nothing to convert and nothing to re-learn.

  • Your ~/.config/hexchat (or %APPDATA%\HexChat) is copied on first start. The original is left untouched.
  • C plugins build unchanged against hexchat-plugin.h, or the new nexchat-plugin.h.
  • Scripts run as they are: import hexchat and import nexchat both work, as do Lua's two names and Perl's HexChat::.
  • Themes (.hct), colors.conf and the HexChat docs all still apply.

install

Build it in a minute.

There are no release packages yet; nexchat builds from source with meson. Flatpak, AUR, a Windows installer and a signed Mac app are on the roadmap.

$ git clone https://github.com/1ay1/nexchat && cd nexchat
$ meson setup build
$ ninja -C build
$ ./build/src/fe-gtk/nexchat

Needs GTK 4.14+, GLib 2.76, OpenSSL and meson 0.59 — every current distribution has them.

$ brew install meson gtk4 openssl@3
$ git clone https://github.com/1ay1/nexchat && cd nexchat
$ meson setup build -Ddbus=disabled
$ ninja -C build app
$ open build/nexchat.app

ninja -C build app makes a self-contained app you can drag into Applications.

$ pacman -S mingw-w64-ucrt-x86_64-{gcc,pkg-config,meson,gtk4,gettext,openssl}
$ git clone https://github.com/1ay1/nexchat && cd nexchat
$ meson setup build -Ddbus=disabled -Dwith-perl=false
$ ninja -C build

In an MSYS2 UCRT64 shell, the same steps the Windows CI runs. An installer is coming; see the roadmap.

IRC isn't going anywhere. Neither is your client.
