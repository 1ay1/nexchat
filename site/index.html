HexChat, continued.

nexchat is an IRC client for Linux, BSD, Windows and macOS. The same HexChat you know — layout, menus, dialogs and keybindings — moved onto GTK4.

Get nexchat Source on GitHub

Familiar, on a current toolkit

HexChat was archived in 2024, still on GTK2. nexchat keeps what people liked about it and fixes what got old.

The layout you know

Channel tree or tabs, topic bar, user list with op and voice icons, the nick button and input box. Every change is checked against screenshots of HexChat.

GTK4

One modern frontend on every platform, with no deprecated GTK calls. HiDPI and Wayland work properly.

Follows your system

Light and dark mode switch with the system, live. Colours you picked yourself stay yours.

At home on macOS

The real menu bar, ⌘ shortcuts, a menu bar icon, the Dock, and a self-contained nexchat.app.

Native tray everywhere

StatusNotifierItem on Linux and BSD, the notification area on Windows, a menu bar item on macOS.

Still a power tool

Scripting in Python, Perl and Lua, FiSH encryption, DCC, logging, URL grabber, user commands — all of it.

Coming from HexChat

Nothing to redo.

  • On first start, nexchat copies ~/.config/hexchat (or %APPDATA%\HexChat) to its own folder. Your HexChat folder is left alone.
  • Plugins keep working: the C API is unchanged (hexchat-plugin.h, or the new nexchat-plugin.h).
  • Scripts keep working: Python has import hexchat and import nexchat, Lua both names, Perl HexChat:: and Nexchat::.
  • Themes (.hct) and colors.conf work the same.
  • The HexChat documentation still applies.

Get it

There are no release packages yet; nexchat builds from source with meson. Packages (Flatpak, AUR, a Windows installer and a signed macOS app) are on the roadmap.

Linux / BSD

git clone https://github.com/1ay1/nexchat
cd nexchat
meson setup build
ninja -C build
./build/src/fe-gtk/nexchat

macOS

brew install meson gtk4 openssl@3
git clone https://github.com/1ay1/nexchat
cd nexchat
meson setup build -Ddbus=disabled
ninja -C build app
open build/nexchat.app

Needs GTK 4.14 or newer, GLib 2.76, OpenSSL and meson 0.59. Windows builds with MSYS2; see the README.
